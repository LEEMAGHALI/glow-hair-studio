# Glow Hair Studio

A responsive salon website concept built with React, Vite and plain CSS.

## Run locally

```bash
npm install
npm run dev
```

## Before publishing

Open `src/App.jsx` and update:

- `WHATSAPP_NUMBER` with the real business WhatsApp number (country code first, no `+` and no leading `0`).
- Services and prices to match the business.
- Gallery images and image descriptions.
- Reviews: replace illustrative sample reviews with real, approved customer testimonials.
- Address, opening hours and Instagram link in the footer.

The current gallery and hero use remote Unsplash image URLs. For a real client project, use images supplied or approved by the business, or properly licensed stock images. You can download approved images into `public/images` and change the URLs to `/images/filename.jpg`.

## Important

This is a fictional portfolio concept. Do not present the sample salon, prices, address, reviews or contact details as a real business. Replace all demo content before using it for a client.

## Build

```bash
npm run build
```

The production files are generated in `dist/`.
